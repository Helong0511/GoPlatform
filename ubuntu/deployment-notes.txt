GoPlatform 单服务部署速记（Ubuntu）

部署方式：二进制 + systemd + Nginx（本仓库不提供 Docker / Kubernetes 部署方案）。

无域名 / 本地开发测试：见 docs/Ubuntu22.04.5超级详细部署指南.md
  - 附录 A：http://<公网IP>/  （Nginx server_name _;  cors 加公网 IP）
  - 附录 B：本机 go run + admin/npm run dev → http://localhost:3000

0) 环境变量
复制 .env.example 为 .env（勿提交 Git）；进程启动时自动加载 .env，已存在的系统环境变量优先。
严格环境（production/staging/uat 等）会校验真实密钥，拒绝 __REPLACE_ME__ 占位符。

1) systemd 服务文件（仅主服务）
sudo vim /etc/systemd/system/ad-platform-main.service

[Unit]
Description=AD Platform Main Service
After=network.target postgresql.service redis-server.service

[Service]
Type=simple
User=root
WorkingDirectory=/data/GoPlatform
ExecStart=/data/GoPlatform/ad-platform-main
Restart=on-failure
RestartSec=10
Environment="ENVIRONMENT=production"
Environment="AUTH_ALLOW_PUBLIC_REGISTER=false"
Environment="DB_DRIVER=postgres"
Environment="DB_HOST=localhost"
Environment="DB_PORT=5432"
Environment="DB_USER=postgres"
Environment="DB_PASSWORD=__REPLACE_ME__"
Environment="DB_NAME=ad_platform"
Environment="REDIS_PASSWORD=__REPLACE_ME__"
Environment="JWT_SECRET=__REPLACE_ME__"
Environment="AES_SECRET_KEY=__REPLACE_ME__"
StandardOutput=journal
StandardError=journal
SyslogIdentifier=ad-platform-main

[Install]
WantedBy=multi-user.target

2) 基础命令
sudo systemctl daemon-reload
sudo systemctl start ad-platform-main
sudo systemctl enable ad-platform-main
sudo systemctl status ad-platform-main

3) 放行端口（按需）
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 8960/tcp
sudo ufw allow 5432/tcp
sudo ufw allow 6379/tcp
sudo ufw allow 6650/tcp
sudo ufw allow 8080/tcp

4) 同步部署资产
sudo cp /data/GoPlatform/scripts/nginx.conf /etc/nginx/
sudo cp /data/GoPlatform/scripts/postgresql.conf /etc/postgresql/15/main/
sudo cp /data/GoPlatform/scripts/ad-platform-main.service /etc/systemd/system/
sudo chmod 644 /etc/systemd/system/ad-platform-main.service
sudo systemctl daemon-reload

5) 构建与重启
cd /data/GoPlatform
go mod download
go mod tidy
go build -o ad-platform-main ./cmd/main.go
sudo systemctl restart ad-platform-main

5.1) 初始化数据库（按 DB_DRIVER 选择）
# PostgreSQL:
psql -U postgres -d ad_platform -f /data/GoPlatform/sql/init_db_PostgreSQL.sql
# MySQL8.0:
mysql -uroot -p -e "CREATE DATABASE IF NOT EXISTS ad_platform CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -uroot -p ad_platform < /data/GoPlatform/sql/init_db_mysql.sql

6) 日志排查
sudo journalctl -u ad-platform-main -n 100 --no-pager
sudo journalctl -u ad-platform-main -f

7) 常用运维
sudo systemctl stop ad-platform-main
sudo systemctl start ad-platform-main
sudo systemctl restart ad-platform-main
sudo systemctl disable ad-platform-main

8) 发布前密钥扫描（在仓库根目录执行）
pwsh ./scripts/check-secrets.ps1

9) 权限初始化说明
`sql/init_db_PostgreSQL.sql` 与 `sql/init_db_mysql.sql` 已包含 report:create 权限初始化，无需再执行旧补丁脚本。
